# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report security problems privately through
[GitHub private vulnerability reporting](https://github.com/clintgalendez/richforever/security/advisories/new),
not as public issues. Include what you found, how to reproduce it and the impact you expect.

You can expect an acknowledgement within 7 days. Fixes are released as soon as practical and credited
in the release notes unless you prefer otherwise.

## Scope

In scope: the addon, the companion, the release workflow and published release assets.

Out of scope: Discord, WoW Forever and Windows themselves, and attacks that require an attacker who
already runs code as the same Windows user.

The security model is described in [docs/SECURITY.md](docs/SECURITY.md).
