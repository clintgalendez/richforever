RichForever companion
=====================

Discord Rich Presence for World of Warcraft: Forever.

1. Install the RichForever addon (separate download) into
   World of Warcraft\_forever_\Interface\AddOns\RichForever
2. Put this folder anywhere you like, for example %LOCALAPPDATA%\Programs\RichForever,
   and run RichForever.exe. It lives in the system tray.
3. Make sure the Discord desktop app runs, with User Settings > Activity Privacy >
   "Share your detected activities with others" on. No Discord setup is needed.
4. Start WoW Forever and keep the small coloured block in the top-left corner of the
   game uncovered. Play in windowed or windowed (fullscreen) mode.

The framework-dependent download needs the .NET 10 Desktop Runtime:
https://dotnet.microsoft.com/download/dotnet/10.0

Uninstall: right-click the tray icon > Exit, run "RichForever.exe --uninstall",
then delete this folder and the RichForever addon folder.

Documentation, troubleshooting and source: https://github.com/clintgalendez/richforever
